===========================================
HƯỚNG DẪN CHẠY GAME SUPER MARIO TRÊN MÁY KHÁC
===========================================

📦 CÁC FILE CẦN THIẾT ĐỂ CHẠY GAME:

1. Toàn bộ thư mục: build/bin/SuperMario/Debug/
   Bao gồm:
   - SuperMario.exe (file chính)
   - Tất cả các file .dll (khoảng 15 file DLL)
   - Thư mục Resources/ (chứa hình ảnh, âm thanh, map)

2. Yêu cầu hệ thống:
   ✅ Windows 7 trở lên (Windows 10/11 khuyến nghị)
   ✅ Visual C++ Redistributable (2015-2022) - có thể cần tải về
   ✅ Card đồ họa hỗ trợ OpenGL (hầu hết máy tính hiện đại đều có)

⚙️ CÁCH ĐÓNG GÓI VÀ GỬI:

CÁCH 1 (Khuyến nghị): Chỉ gửi thư mục cần thiết
   - Nén thư mục: build/bin/SuperMario/Debug/
   - Gửi file ZIP này
   - Người nhận giải nén và chạy SuperMario.exe

CÁCH 2: Gửi toàn bộ dự án (không khuyến nghị vì nặng)
   - Nén toàn bộ thư mục dự án
   - Người nhận chỉ cần thư mục build/bin/SuperMario/Debug/

⚠️ LƯU Ý QUAN TRỌNG:

1. Visual C++ Runtime:
   Nếu máy đích chưa có Visual C++ Runtime, có thể gặp lỗi:
   "The program can't start because MSVCP140.dll is missing" hoặc tương tự
   
   Giải pháp: Tải và cài đặt Microsoft Visual C++ Redistributable:
   Link: https://aka.ms/vs/17/release/vc_redist.x64.exe
   (hoặc tìm "Visual C++ Redistributable 2015-2022" trên Google)

2. Cấu trúc thư mục:
   QUAN TRỌNG: File SuperMario.exe PHẢI ở cùng thư mục với các file .dll
   và thư mục Resources/ phải ở cùng cấp với SuperMario.exe

   Cấu trúc đúng:
   SuperMario/
   ├── SuperMario.exe
   ├── glew32.dll
   ├── libcrypto-1_1.dll
   ├── ... (các DLL khác)
   └── Resources/
       ├── map/
       ├── music/
       └── ... (các file khác)

3. Lỗi có thể gặp:
   - Thiếu DLL: Cài Visual C++ Redistributable
   - Không tìm thấy Resources: Đảm bảo thư mục Resources ở đúng vị trí
   - Lỗi OpenGL: Cập nhật driver card đồ họa

📝 KHUYẾN NGHỊ:

Để đảm bảo game chạy tốt nhất, bạn nên:
1. Test trên máy khác trước khi gửi
2. Hoặc build phiên bản Release (nhẹ hơn và ổn định hơn Debug)
3. Tạo file hướng dẫn đơn giản kèm theo

🔧 BUILD PHIÊN BẢN RELEASE (Tùy chọn):

Nếu muốn build phiên bản Release (nhẹ và chạy nhanh hơn):
   cmake --build build --config Release

File sẽ ở: build/bin/SuperMario/Release/
